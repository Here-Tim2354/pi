# 引言

本文档专门记录forked Pi后对于自定义实现，上游更新的采纳与决策倾向。

# 自定义实现

**截至目前**，我对所有的自定义实现都是走`.pi/extensions-src`官方提供的接口。这种写法可以做到极低的耦合。

因此，上游的更新可以安全地进入本仓库的同时，不会起太多冲突。

# 拓展与包

拓展（extension）在本地仓库中是`.pi/extensions-src`，而非`.pi/extensions`，这是有意区分。详情见2026-09-01的改动。

包：包的声明永远在全局。不保存在本地中。我的想法是：社区包我通常不打算对其进行直接修改。故不走git管理。
