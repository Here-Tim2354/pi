# TLDR

1. `npm run sync` 扩展为全量配置镜像：包、扩展、skills、prompts 全部单向复制到全局
2. 新增 `--plugins-only` 模式

> 本篇是过渡方案，08-19 已回撤。留档的价值在教训。

## 1-镜像

**背景**：想让全局 pi 环境完全由仓库状态驱动，任何机器 `npm run sync` 完就是一致体验。

**决策**：sync 在装包之外追加镜像逻辑——按 `.pi/settings.json` 装卸全局包、复制 `.pi/extensions/*.ts` 到 `~/.pi/agent/extensions/`、单向复制 `.pi/skills` 和 `.pi/prompts`。

## 2-教训

**背景**：pi 会自动发现仓库内 `.pi/extensions/`。镜像又把同一批文件复制到全局。

**设计**：两者叠加 = 同一工具双重注册（"Tool conflicts with"），仓库内启动直接坏掉。这条边界决定了后续所有 sync 设计，最终产物是 09-01 的 `extensions-src` 更名。
